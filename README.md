# 🌈 SDGs 17 조각 정원 — SDGs 17개 목표를 한 조각씩 채우는 실천 다짐 저금통

한 사람의 **실천 다짐**이 퍼즐 한 조각이 되고, 모두의 실천이 모여 **숨이 찬 지구를 초록 지구로** 바꾸고 SDGs 17색 바퀴를 채워 가는 웹 공간이에요.
초·중·고 누구나 쓸 수 있고, 앱 설치·회원 가입·개인정보 수집이 없어요.

> 📗 처음이라면 **`수정방법.html`** 을 더블클릭해서 열어 보세요.

## 구조
```
학습하기(학교급별 3분 + 확인 퀴즈) → 실천 다짐(기후·자원·생명) → SDGs 약속 카드 선물 → 퍼즐 조각 저금
다짐 1번 = 1조각 → 100조각 = 그림 1점 → 300조각(그림 3점) = 앨범 1권
그림 3점: ① 숨이 찬 지구 → ② 다시 숨 쉬는 지구 → ③ 초록 지구
```

| 중학 | 환경 문제의 원인 · 지속가능한 발전 · SDGs | 원인과 해결 | 투명성 |
| 고등 | 지속가능발전과 형평성 · 외부효과 · 공유지의 비극과 협력 | 경제 개념과 연결 | 공공성·연대성 |

## 이론적 배경
- 공유지의 비극(하딘, 1968)과 공유자원 관리(오스트롬) → 협력이 눈에 보이는 공동 그림
- 실행 의도(골위처) → 실천을 직접 고르고 약속
- 사회적 규범과 넛지 → 실시간 조각 수·온도계
- 세계시민교육 3영역(유네스코): 인지 → 사회·정서 → 행동 → 학습하기 → 문장 카드 → 다짐
- 지속가능발전교육(ESD)

## AI 윤리
앱 안 **🤖 이 앱의 AI 윤리** 화면에서 국가 인공지능 윤리기준(2020) 10대 핵심요건(인권 보장, 프라이버시 보호, 다양성 존중, 침해 금지, 공공성, 연대성, 데이터 관리, 책임성, 안전성, 투명성)에 따라 앱을 점검한 내용을 보여 줘요.

## 고쳐 쓰기
- `index.html` 맨 위 **SCHOOL 설정**: 제목, 말풍선, 만든 곳 표기
- `ROUTINES_BY`: 학교급별 실천 다짐 / `CARDS_BY`: 학교급별 문장 카드 / `LEARN`: 학습하기 화면과 퀴즈
- 그림: `pic1~3.png`(가로:세로 4:3), 캐릭터 `principal.png`·`mascot_girl.png`·`mascot_boy.png`, 교표 `emblem.png`, 배경 `scene.jpg`

## 인터넷에 올리기
- **간단히(조각은 기기마다 따로 저장):** 깃허브 저장소에 파일을 올리고 Settings → Pages → main / (root) → Save
- **학교 전체 조각을 하나로 세기:** 클라우드플레어 Pages + D1 (Build command `exit 0`, 출력 폴더 `/`, D1 바인딩 이름 `DB`, `schema.sql` 실행)
